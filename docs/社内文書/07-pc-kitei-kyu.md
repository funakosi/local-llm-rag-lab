# PC貸与規定（旧版・参考）
文書番号：情規-IT-001　版数：第2版　制定日：2024年4月1日
状態：2026年6月1日付で廃止。履歴確認用として保管。

## 1. 適用について
本書は2026年5月31日までの運用基準であり、現在の新規貸与・更新・再貸与には適用しない。現行規定は「01-pc-kitei.md」（第3版）を参照する。古い申請記録を確認する場合に限り、本書の基準を参照する。

## 2. 貸与と更新
旧基準では、業務上PCが必要と承認された従業員に会社指定PCを貸与する。標準更新周期は貸与開始日から**3年**とする。故障時は情報システム部の判断により交換する。新機種への希望は上長承認があれば検討対象としていたが、必ずしも交換を保証するものではない。

## 3. 社外利用
社外利用時は会社指定VPNを利用する。接続前にウイルス対策ソフトの状態を確認し、接続先が会社指定であることを確認する。詳細手順は当時のVPN手順書に従う。

## 4. 返却
退職者は原則として最終出社日までにPCを返却する。返却前のデータ処理は情報システム部の指示に従う。

## 5. 廃止に関する注意
本書の更新周期「3年」および旧運用に関する記述を現行ルールとして案内してはならない。新旧の数値が検索結果に同時に現れた場合、版数と施行日を確認すること。現行規定の更新周期は4年である。
