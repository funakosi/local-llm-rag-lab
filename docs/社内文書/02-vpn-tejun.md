# リモート接続手順書
文書番号：情手-IT-014　版数：第2版　更新日：2026年7月10日
主管部署：情報システム部

## 1. 目的
本手順書は、会社貸与PCから社外ネットワーク経由で社内システムに接続する際の標準手順を定める。PCの利用条件は「01-pc-kitei.md」、アカウントの有効条件は「03-account.md」に従う。アカウントが停止中、または多要素認証の登録が未完了の場合は、VPN接続を試みる前にヘルプデスクへ連絡する。

## 2. 接続前の確認
次の順序で確認する。順番を入れ替えず、すべて完了してから接続を開始する。
1. 会社貸与PCであること、資産管理ラベルが剥がれていないことを確認する。
2. OSのセキュリティ更新とウイルス対策が有効であることを確認する。
3. 自宅など信頼できるネットワークに接続する。公共Wi-Fiを使う場合は、接続先名称を確認し、偽アクセスポイントが疑われる場合は接続しない。
4. PCの日付と時刻が自動設定されていることを確認する。
5. 会社アカウントでOSにサインインし、多要素認証（MFA）が利用可能であることを確認する。
確認に失敗した場合は、自己判断でセキュリティ機能を停止せず、ヘルプデスクへ連絡する。

## 3. VPN接続手順
1. 会社指定のVPNクライアントを起動する。
2. 接続先として「CORP-REMOTE」を選択する。似た名称の個人用・検証用接続先は選択しない。
3. 会社アカウントで認証し、MFAの要求を承認する。身に覚えのないMFA要求は承認せず、05-incident.mdの事故報告手順に従う。
4. 接続状態が「接続済み」と表示されることを確認する。
5. 社内ポータルを開き、アクセスできることを確認する。
6. 作業終了後は、VPNクライアントから切断する。PCをスリープさせるだけで切断したものとみなしてはならない。

## 4. 接続できない場合
認証エラーが表示された場合、パスワードを何度も連続入力しない。まずエラーコードと発生時刻を控え、ヘルプデスクへ連絡する。アカウントロックが疑われる場合は「03-account.md」のロック解除条件を確認する。ネットワークエラーの場合は、ネットワークを一度確認して再試行を1回だけ行う。それでも失敗する場合は、別のVPNソフトをインストールせず、ヘルプデスクへ連絡する。
MFA端末を紛失した場合は、代替手段を自己判断で設定しない。アカウント停止が必要となる可能性があるため、03および05の基準に従って連絡する。

## 5. 利用上の禁止事項
VPN接続中に、会社データを個人用クラウドストレージへ転送してはならない。家族共用PCや私物PCから会社VPNへ接続してはならない。VPN接続情報、MFAコード、回復コードを他人に共有してはならない。画面共有や遠隔支援を受ける場合は、会社が承認したツールを利用し、認証情報を画面に表示しない。
