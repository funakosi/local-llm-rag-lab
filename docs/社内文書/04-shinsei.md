# ソフトウェア・機器購入申請規定
文書番号：情規-PROC-003　版数：第2版　施行日：2026年5月20日
主管部署：総務部・情報システム部

## 1. 適用範囲
本規定は、業務用ソフトウェア、PC周辺機器、ネットワーク機器、クラウドサービスの新規購入および有償契約の更新に適用する。会社貸与PC本体の標準更新は「01-pc-kitei.md」と「08-kishu-hyo.md」に従う。無料サービスであっても、会社データを保存・処理する場合は情報システム部のセキュリティ審査が必要である。

## 2. 申請前の確認
申請者は、購入目的、利用者、必要性、希望納期、費用負担部署、データの保存先、契約期間を記載する。同等の承認済み製品がある場合は、既存製品を優先する。購入前に承認を得ることを原則とし、発注後の事後申請は認めない。緊急時の例外は、部門長と総務部長の事前承認を得た場合に限る。

## 3. 金額別承認ルート
金額は消費税・送料・初期費用を含む総額で判定し、同一目的の購入を分割して承認段階を回避してはならない。
- 3万円未満：直属上長の承認。情報システム部によるセキュリティ審査は別途必要となる場合がある。
- 3万円以上20万円未満：直属上長および部門長の承認。
- 20万円以上100万円未満：直属上長、部門長、総務部長の承認。
- 100万円以上：直属上長、部門長、総務部長、管理本部長の承認。
承認者は、申請額が境界値ちょうどの場合は上位の区分を適用する。例えば20万円ちょうどの場合は総務部長まで、100万円ちょうどの場合は管理本部長まで承認が必要である。

## 4. 情報システム部の審査
次のいずれかに該当する場合、金額にかかわらず情報システム部の事前審査を受ける。
- ソフトウェアをPCにインストールする。
- SaaSやクラウドサービスへ会社データを入力・保存する。
- ネットワークに接続する機器を購入する。
- 管理者権限、VPN、外部共有などの追加権限を必要とする。
審査では、情報の種類、保存場所、外部送信、認証方式、契約終了後のデータ削除、ライセンス条件を確認する。審査が未完了の状態では購入・利用を開始してはならない。

## 5. 申請から購入まで
1. 申請者が申請フォームを作成する。
2. 直属上長が業務上の必要性と予算を確認する。
3. 金額区分に応じて部門長、総務部長、管理本部長の承認を得る。
4. 第4項に該当する場合は、情報システム部の審査完了を確認する。金額承認とセキュリティ審査は並行できるが、両方が完了するまで発注しない。
5. 総務部が発注し、申請番号と納品日を記録する。
6. 情報システム部が必要に応じて資産台帳へ登録する。
申請者が自ら発注できるのは、総務部から委任された定型購入に限る。

## 6. 例外・緊急購入
業務停止など緊急性が高い場合でも、事後申請を常態化させてはならない。緊急購入の例外は、部門長と総務部長が購入前に承認し、翌営業日までに申請記録を補完する。セキュリティ審査対象である場合、緊急性を理由に審査を省略できない。規定の例外承認とセキュリティ審査は別の手続きである。
